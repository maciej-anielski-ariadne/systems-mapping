Critical correctness

User-authored text can destroy its own round-trip

C01Multiline CSV fields corrupt maps, dropping boxes, links, and review records
CorrectnessData lossHigh confidence

The serializer correctly quotes line breaks, but the parser splits the document into physical lines before it parses quoted records. A multiline description or review note written by the app cannot be read back by the app.

Evidenceassets/js/05a-csv-serializer.ts:39–50 quotes line breaks; assets/js/05-csv-parser.ts:78–119 splits on every newline first. Textareas accept multiline descriptions at assets/js/15-detail-panel.ts:165–169 and :1593–1595.

Verified failure: serializing and reloading First line↵Second line reports success but drops the box; its links disappear with it. Review notes truncate or corrupt similarly.

Remediation: parse complete RFC 4180 records with quote state preserved across physical lines, preferably through a proven CSV parser. Pin LF, CRLF, quote, and comma round-trips for descriptions, labels, and review notes.

High priority

Correctness and release confidence

These defects either mutate the wrong thing, resurrect or erase state, crash a supported workflow, create unsafe rendering boundaries, or invalidate the reliability of the default validation pipeline.

H02A rejected import resets edge allocation and gives later edges duplicate IDs
ImportEditingVerified

The edge counter resets before fatal validation. A failed import retains the old graph but leaves allocation at zero; the next new edge can reuse an existing ID. Selection can then resolve the wrong edge, and deletion removes every edge sharing that ID.

Evidenceassets/js/06-data-loader.ts:595–618, :167–178; assets/js/16e-canvas-edit.ts:1541–1561 and :1684–1694.

Remediation: derive the next unused ID only after successful commit, inside the atomic map-lifecycle transaction.

H03Stale search results survive map replacement and crash when activated
SearchImportVerified

Successful load does not clear the search query, match objects, or focused result. Activating a result from the previous map passes an absent node ID into traversal, which assumes adjacency exists and throws.

Evidenceassets/js/06-data-loader.ts:907–929; assets/js/17a-search.ts:374–399; assets/js/09-graph-selection.ts:49–70 and :272–299.

Remediation: clear search atomically on every replacement and defensively reject unknown IDs in selection and focus primitives.

H04Undo erases Review audit records despite their stated non-undoable contract
ReviewUndoAudit integrity

Undo snapshots contain the complete CSV, including reviews. Restoring an older model snapshot therefore restores an older review log too. A verdict recorded after an edit disappears when that edit is undone.

Evidenceassets/js/24-review-record.ts:517–569; assets/js/16f-canvas-mutations.ts:67–76; assets/js/16g-canvas-undo.ts:104–120 and :251–319; assets/js/06-data-loader.ts:930–978.

Remediation: separate model-history snapshots from the audit log, or reconcile current reviews during model restoration.

H05New map retains parameters, reviews, search, selection, and other old-map state
New mapState lifecycleVerified

bootEmptyStateGrid resets graph collections and a subset of UI state, not the full map-scoped state. Old review entries become tombstones, old parameters remain exportable, and reused IDs can inherit old metadata.

Evidenceassets/js/17-events.ts:122–133; assets/js/16e-canvas-edit.ts:418–471; review reconciliation at assets/js/06-data-loader.ts:272–276.

Remediation: use one atomic replacement/reset routine with an explicit inventory of map-scoped and session-scoped state.

H06A pending autosave can resurrect the old map after New map
PersistenceRaceVerified

Clearing the stored CSV does not cancel the debounce timer or invalidate its pending payload. An edit followed immediately by New map can write the old CSV back after the empty map appears; refresh restores the old map.

Evidenceassets/js/04a-storage.ts:65–111; assets/js/17-events.ts:122–133.

Remediation: cancel timers and pending payloads on clear, using a storage generation token or an atomic empty-state write.

H07Reading and simulation modes still allow keyboard mutation of a selected edge
Mode safetyEditingVerified

Edge selection is mode-agnostic, and Arrow-key effect cycling runs before the edit-mode guard. In reading mode, select an increases edge and press ArrowRight: it becomes decreases and is persisted.

Evidenceassets/js/16e-canvas-edit.ts:293–342, :554–561, and :1574–1609; assets/js/09-graph-selection.ts:386–429.

Remediation: require edit mode and inactive simulation for every mutation capability; keep read-only edge focus separate from editable selection.

H08Formula dependencies without arrows compute in the wrong order
SimulationFormulaVerified

The solver knows formula references are dependencies, but the cold sweep order is derived only from visual edges. The loader warns about a missing arrow yet retains the formula. If the target precedes its source in edge order, it consumes the seeded source value and can finish wrong.

Evidenceassets/js/06-data-loader.ts:196–242 and :391–439; assets/js/07-simulation-engine.ts:330–352 and :665–777.

Verified failure: with B = a * 2, no A→B arrow, and A moved from 100 to 200, B remains 200 instead of 400 when B is scheduled first.

Remediation: either reject formulas missing dependency links or schedule from formula dependencies rather than presentation edges.

H09Prototype-key IDs can crash import
ImportIdentifier safetyVerified

External IDs populate plain objects. Values such as __proto__, constructor, or toString collide with inherited properties; solver dependency code later assumes retrieved values are arrays.

Evidenceassets/js/06-data-loader.ts:137–178 and :661–808; assets/js/07-simulation-engine.ts:330–352.

Verified failure: importing a node named __proto__ throws back.includes is not a function.

Remediation: use Map or null-prototype dictionaries and reject reserved keys through the shared schema validator.

H10Imported identifiers and colours cross unsafe string-rendering boundaries
SecurityImportAll renderers

Node, stream, category, and colour values are accepted without a canonical grammar or strict colour validation, then interpolated raw into SVG and HTML attributes. A quote-bearing CSV can corrupt markup and potentially inject active SVG attributes. The same values flow into simulation and exported viewer markup.

Evidenceassets/js/06-data-loader.ts:621–641 and :668–676; live SVG at assets/js/11-rendering.ts:1031–1037, :1105–1116, and :1261–1270; simulation at assets/js/14-simulation-panel.ts:99–104; export at assets/js/19-export.ts:578–716.

Remediation: validate at the input boundary and use distinct text, attribute, selector, and CSS-value handling or DOM construction at every output boundary. Add adversarial import/export tests.

H11Atlas stores one wheel edge key and looks up another, so selected chords cannot light
AtlasInteractionSource proof

Wheel paths store from + U+0001 + to. paintWheel constructs its selected-link set with from + "" + to. Those strings cannot match, so the chord’s .on state is never applied.

Evidenceassets/js/21-atlas-view.ts:646–652 versus :1928–1935.

Remediation: introduce one typed wheelEdgeKey function and assert the exact selected chord set in the Atlas DOM test.

H12Review’s “Include it in the formula” auto-fix is mathematically inert
ReviewSimulationMisleading fix

The proposed fix multiplies the existing formula by source / source. That is one for every nonzero value, so it clears a reference-based warning without making the source causal; at zero it can create 0/0.

Evidenceassets/js/22a-review-model.ts:341–346. Proposal ranking rewards cleared findings at :406–419.

Remediation: remove this proposal until meaningful current-to-baseline ratio semantics exist, or require an owner-authored expression. A proposal test must move the source and prove the target changes.

H13CI runs Node 20 against a jsdom release that requires newer Node
CIDependenciesRelease

CI pins Node 20. The lockfile pins jsdom@30.0.1, which declares ^22.22.2 || ^24.15.0 || >=26. The project declares no Node engine and the README names none.

Evidence.github/workflows/ci.yml:13–16; package-lock.json:1937–1967; package.json.

Remediation: align CI, package.json.engines, and README on Node 24.15+ or 26, or downgrade jsdom to a version supporting Node 20.

H14The normal green test run depends on declaration order
TestsIsolationReproduced

The test DOM is mounted once per file and only localStorage is consistently reset. Mutable app state, modes, filters, reviewer identity, timers, and module caches leak between tests.

Evidencetests/setup.ts:87–98. npx vitest run --sequence.shuffle --sequence.seed=303 failed five tests: CSV serializer, Review record, Review rail, simulation rendering, and filters. Each also fails when shuffled alone.

Remediation: create a complete application-state fixture, reset timers/listeners/caches, and run a fixed shuffled seed in CI.

Behavioral drift, performance risk, accessibility, and evidence gaps

M01Numeric validation is permissive and inconsistent across import, Bulk edit, and direct edit
SchemaSimulation

parseFloat accepts prefixes such as 12xyz and non-finite values; baseline documentation says positive while import and builder reject only zero; direct editing allows negative baselines and crossed bounds that reload differently.

Evidenceassets/js/05-csv-parser.ts:131–138; 06-data-loader.ts:734–806; 16a-builder-state.ts:490–508; 15-detail-panel.ts:1571–1667.

Remediation: one strict finite-number validator and the same constraints at every authoring surface.

M02Direct import does not enforce unique, usable row, column, or category IDs
SchemaImport

Only node IDs receive duplicate checks. Duplicate or blank dimension IDs can satisfy raw-section validation while indexes and layout collapse them inconsistently; Bulk edit already rejects the same defects.

Evidenceassets/js/06-data-loader.ts:605–675; builder validation at assets/js/16a-builder-state.ts:451–508.

Remediation: share the builder’s schema validator with direct import and validate fully before state mutation.

M03Atlas and detail navigation bypass the non-toggle focus primitive
NavigationCross-mode synergy

focusNode exists specifically because navigation must not toggle off an already-selected box. Atlas return-to-map and detail link navigation still call selectNode; returning to the selected start or following a self-loop can empty the panel.

Evidenceassets/js/09-graph-selection.ts:301–323; 21-atlas-view.ts:3218–3224; 15-detail-panel.ts:1283–1292.

Remediation: route every navigation surface through focusNode and one contract test.

M04Scroll-to-box ignores render zoom
NavigationZoom

scrollNodeIntoView centres unscaled layout coordinates while the SVG uses scaled dimensions. Search, Review, detail, undo, and Atlas navigation can land away from distant targets at any zoom other than one.

Evidenceassets/js/09-graph-selection.ts:472–483.

Remediation: centralize layout-to-scroll conversion using committed render zoom; test far corners at 0.4×, 1×, and 2×.

M05Focus breadth counts hidden boxes despite claiming to measure visible boxes
FiltersSelection

The contract says the threshold follows what is visible, but numerator and denominator both use all nodes. Hiding many rows, columns, or categories can suppress wide-focus styling even when most visible boxes are lit.

Evidenceassets/js/09-graph-selection.ts:212–224.

Remediation: compute visible-lit over visible-total from cached filter/layout state.

M06Collapsed-edge keys assume IDs cannot contain a delimiter the loader permits
Collapsed viewsIdentifier safety

Collapsed connectors use from + "->" + to. Because IDs may contain ->, two different pairs can collide and merge or suppress connectors.

Evidenceassets/js/10a-collapsed-edges.ts:98–99; no matching constraint at 06-data-loader.ts:668–676.

Remediation: nested maps, tuple identity, or length-prefixed keys, backed by the canonical identifier grammar.

M07The mutation funnel over-invalidates simple edits but is bypassed for later edge cycles
RedundancyCorrectnessPerformance

Descriptions and line styles pay for indexes, layout, solver, Review, sweep, full render, and serialization. By contrast, second and later edge-effect keypresses use a copied partial pipeline that omits Review and sweep invalidation, leaving derived results stale during a cycle session.

Evidenceassets/js/16f-canvas-mutations.ts:67–103; 15-detail-panel.ts:1592–1694; partial path at 16e-canvas-edit.ts:1612–1631.

Remediation: one capability-aware transaction with explicit topology, geometry, calculation, presentation, review, persistence, and history dirtiness.

M08Review can perform roughly two dozen full solves for one three-proposal card
PerformanceReviewStatic risk

Validation solves; preview performs two validations and two additional solves; ranking previews every proposal; the panel asks for proposals while finding fixability and again while preparing the card, then previews the selected proposal once more when expanded.

Evidenceassets/js/22a-review-model.ts:102–217 and :374–419; assets/js/23-review-panel.ts:302–390.

Remediation: revision-keyed baseline caching, one after-snapshot per proposal, cheap collapsed-card predicates, and lazy proposal generation on expansion. Benchmark 300 nodes with 20 and 100 findings.

M09One Atlas paint repeats whole-model derivations and blocked cuts approach O(B×E)
PerformanceAtlasStatic risk

Path, share, effect, route, and trace derivations repeat within one paint; blocked-node propagation scans the surviving edge set for every blocked element. Slider scrubbing on a dense Atlas repeats much of this work each frame.

Evidenceassets/js/21-atlas-view.ts:1603–1665, :2142–2183, and :2245–2585.

Remediation: a revision-keyed AtlasPaintSnapshot plus outgoing adjacency for O(V+E) cut propagation; measure p95 frame time at the 300-box target.

M16Strict TypeScript is effectively absent at the Atlas boundary
MaintainabilityAtlasDe-duplication

The 1,034-line Atlas engine contained 284 any occurrences; the 3,273-line view contained 226. The wheel-key mismatch was exactly the kind of defect branded element and edge-key types should prevent.

Original evidencetsconfig.json enabled strict mode, but assets/js/20-atlas-engine.ts and 21-atlas-view.ts opted out locally through any.

Resolution: Closed. The engine now exports typed graph, lane, loop/tangle, wheel, sequence, result, measurement, and strand contracts; the view consumes those contracts through typed graph, world, reading, fork, trace, and paint state. Explicit any, unknown escape types, chained assertions, suppression comments, and unvalidated DOM casts are absent. WheelEdgeKey remains opaque behind one reviewed constructor and a validating DOM parser. Atlas-scoped lint prevents regression, while compile-time contract tests preserve application-specific graph fields and behavioral tests protect opaque fork handles, folded lanes, exact path counts, strands, loops/tangles, current reading, and wheel chord selection.

Review method

  • Three parallel specialist passes: correctness/state/persistence; architecture/redundancy/performance; tests/documentation/build/accessibility.
  • Deliberate overlap on correctness and architecture; findings were consolidated only after file-and-line cross-checking.
  • Targeted temporary probes reproduced multiline round-trip loss, edge-ID collision after rejected import, stale-search activation, Review/undo loss, New-map state leakage, autosave resurrection, read-mode edge mutation, formula scheduling, prototype-key crashes, and numeric inconsistency. No probe remains in the repository.
  • Actual runtime mode transitions and responsive measurements were checked in the served app, not inferred from unit tests.
  • Implementation used three parallel workstreams plus an integration pass. Every verified failure received focused regression coverage before the full suite.
  • Performance findings M08 and M09 were addressed through Review snapshot caches, lazy proposals, one Atlas paint snapshot, and adjacency-based cut propagation.
