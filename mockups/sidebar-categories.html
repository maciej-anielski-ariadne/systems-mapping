Sidebar — Primary / Secondary categories as separate headings

Split the single Categories list into two labelled groups: Primary (fill) and Secondary (chips). Left = today (one list with a per-row "chip" checkbox). Right = the proposed split.

Key decision: with separate headings the per-row "chip" checkbox is redundant (the heading already says the class). So to move a category between groups, hover a row and click a small → chip / → fill button (it jumps to the other group). Each group gets its own + Add so a new category lands in the right class.
