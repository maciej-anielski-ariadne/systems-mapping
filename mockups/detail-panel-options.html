Right detail panel — aligned, accessible, and one skeleton across view & edit

Three cumulative options. The dashed amber guide marks the single label axis; the dashed blue guide marks the shared value rail (88px). Toggle ✎ Edit mode to switch the panel between view and edit — on Current it's a different layout (it jumps); on C the layout stays put and fields unlock in place. ⇄ Split compares against today.

The ladder. ● A — Align (CSS-only): one label axis (the heading/quant/edge step → gutter+stripe) and one value rail for quant values, elasticities & counts. ● B — + accessibility: edge rows become real <button>s (Tab + Enter, focus ring), the dark category-swatch ring → white (matches the left sidebar), reduced-motion + aria-pressed toggle. ● C — Converge view↔edit: one skeleton renders both modes; toggling Edit swaps only each field's leaf (span ↔ input) in place — no layout swap. A+B folded in.
Recommendation — Option C (your chosen direction). The view & edit modes are currently two different DOM trees, so toggling reads as a rebuild. C is the only option that fixes that root cause — and it's cheaper than it looks: the view edge-rows and edit edge-editors are already the same stripe frame, the name/quant rows already rhyme, and the tag row is already shared. A and B land first as safe, independent steps.
