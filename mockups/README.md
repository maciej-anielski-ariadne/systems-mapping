# `mockups/` — design sketches (not the app)

Throwaway, standalone HTML files used to explore UI options before building them for
real — different sidebar layouts, edge line styles, spacing, node-name wrapping, and so on.

**These are not part of the shipped application.** Nothing in `index.html`, the build, or
the tests loads them. They're kept only as a visual record of design exploration. Open one
directly in a browser if you're curious; otherwise it's safe to ignore this folder entirely.
