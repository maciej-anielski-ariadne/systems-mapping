Edge line styles

Investigation result: real edges are already drawn solid by default. The only edges that render dashed are synthetic "through" edges (a causal link auto-re-routed when a stream/stage/category is hidden) and the brief draft edge while you drag to create one. Below: what a per-edge dashed option would look like, and the choices for the synthetic edge. Edges are drawn with the app's real bezier + arrowheads and colours.

Nothing is built yet. Pick what "dashed" should mean and what to do with synthetic edges, and I'll implement it.

1 · Real edges — solid (today, unchanged) baseline

2 · New: a per-edge dashed option to add

A new per-edge style (solid = default, dashed = opt-in) you'd set on an edge — useful to mark a link as weak / uncertain / planned. Same colours and arrowheads, just a dashed stroke.

3 · How edges look when a node is selected solid vs dashed

Selecting a node traces its causal chain: node borders glow (blue = upstream cause, amber = downstream impact, white = the selected node); edges on the trace become bold + coloured with an arrowhead, edges off the trace dim almost to nothing (~0.05 — shown a little brighter here so you can see it). A dashed edge keeps its dashes in every state.

4 · Synthetic "through" edge chosen

Appears when a hidden stage/stream/category sits between two nodes, so the app re-routes the causal path as one derived arrow. New behaviour: drawn thinner than a real edge (so it still reads as derived), and it inherits dashing from the underlying edge(s) it re-routes — thin solid when they're all solid, thin dashed if any link in the hidden chain is dashed. (For reference, the old always-dashed 1.5 px look is shown last.)
