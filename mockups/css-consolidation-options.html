Consolidating the visual language — least to most disruptive

Four cumulative options for tightening the app's CSS, each a strict prerequisite for the next. Every option is previewed live below: pick a tier in the top bar and the faithfully-reproduced app surfaces — header, sidebar, map, detail panel, simulation, every popup, toast and control — re-skin in place. Turn on ⇄ Split to see Current and the chosen tier side by side. This page loads the app's real Fraunces / IBM Plex Sans / IBM Plex Mono webfonts, so Tier 3 and Tier 4 render in the actual typefaces the app ships but currently never uses.

The four tiers. ● Tier 1 — Truth & tokens: zero visible change; the code stops lying (dead borders, dead fonts, duplicate colours). ● Tier 2 — One system: subtle; collapse ~5 button / field / label / card variants into single primitives, commit to the flat look. ● Tier 3 — Hierarchy & type: visible; switch on the real fonts (tabular numerics, crisp labels), fix WCAG contrast, rank the header & sidebar. ● Tier 4 — Maximal minimal: significant; two fonts, near-monochrome, the map shows ≤3 meanings at once.
Recommendation. Ship Tier 1 now (no design sign-off needed — it only deletes provably-dead code and fixes latent bugs). Follow with Tier 2. Treat Tier 3 as the target end-state for most users — turning on IBM Plex is the single highest value-per-effort change in the audit. Reserve Tier 4 for a deliberately scoped redesign once 1–3 are live. No functionality is removed at any tier.

The rgb of --accent-blue written by hand at 10 different opacities (.06–.55) for focus rings, selection tints and glows — none re-themeable. --accent-orange is defined but referenced 0×.

Glass & grid are hardcoded too token bypass

Both overlay scrims and the viz-control glass are hand-written alphas of existing bg tokens (rgba(17,24,39,.85)=--bg-deep; rgba(10,14,26,.92)=--bg-deepest); the 32px grid tint is --border-strong. All are color-mix() candidates.

Structure — dead code & missing scales

Borders that render nothing dead code
84 border declarations, all wiped

12-no-borders.css applies border:0 !important globally. So 84 border-family declarations (≈38 border: shorthands) are dead — and a few carried real intent, e.g. two colour-swatch hairlines that now vanish on dark backgrounds, and the drop-zone's drag highlight.

No radius / motion scale ad-hoc
7 → 5 border-radius values

Radii of 2,3,4,5,6,8,12px and 6 transition durations (.1/.12/.15/.18/.2/.22s), with 5 transition: all. Snap to a 5-step radius + 3-step motion scale.

Repeated recipes duplication

Same pattern, many copies: the uppercase-mono micro-label 28×, the blue focus-ring 8×, the coloured left-stripe row 3×, and ~5 near-identical button definitions. Each collapses to one primitive.

Accessibility — surfaced by the cross-check

Label colour fails WCAG AA contrast

--text-tertiary #6b7691 colours the most-common label idiom (~49 sites, 9–11px) yet fails AA on every background:

label on bg-mid — ratio 3.58
AA-safe (Tier 3) — ratio 4.9
No keyboard focus on buttons focus

:focus rings exist only on form inputs; no :focus-visible anywhere on the action buttons (header, detail, builder, sim, zoom), and outline:none removes the default. Tab a button → no visible focus. Tier 2 adds a shared ring (try Tab on the live header below at Tier 2+).

Motion ignores user preference reduced-motion

prefers-reduced-motion is honoured in only 2 builder rules. Five keyframes (the 1.4s undo pulses) and ~37 transitions ignore it. Tier 3 adds a global guard.

Hover-only = touch/keyboard dead-end reachability

Row delete / reclassify use opacity:0 revealed only on :hover (9 sites). No :focus-within and no @media(hover:hover) — unreachable by touch or keyboard. Tier 3 reveals them on focus too.
